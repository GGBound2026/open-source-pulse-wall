# 进阶积分与皮肤玩法说明

> **先说明一下**：积分、皮肤和卡片动画都是**完全可选的趣味玩法**。即使不点 Star，也完全不影响你正常上墙、写寄语、提 Issue 以及完成整场 Git 培训。
>
> 如果你完成主线任务后还想玩点更有意思的，可以顺手点一下仓库右上角的 **Star** 开启这套皮肤和积分玩法（大约 30 秒至 3 分钟内自动同步，回到展示墙点一下「立即刷新」就能看到变化）。

- 查看贡献教程：[CONTRIBUTING.md](./CONTRIBUTING.md)

## 一、积分获取规则（全自动统计）

展示墙会自动解析 GitHub Star、已合入 `main` 的寄语文件与 Commit 协作记录，无需任何人工登记：

| 玩法项目 | 分值 | 上限 / 判定规则 | 说明 |
| --- | --- | --- | --- |
| **1. 给本仓库点 Star** | **+1 分** | 上限 **1 分**（入轨开关） | 点亮 Star 即进入星系排行榜，并直接解锁专属卡面皮肤与 16 种顶格破框特效之一 |
| **2. 给不同同学写寄语（Cheers）** | **+1 分 / 人** | 上限 **3 分** | 每给 1 位**不同的、非本人**已上墙同学合入寄语 PR 计 1 分；重复给同一人修改/重写不重复加分 |
| **3. 结对编程（`Co-authored-by`）** | **+2 分 / 搭档** | **不封顶**（按不同搭档叠加） | 与另一位已上墙同学共同合入 1 个有实质文件改动的 commit，**双方各 +2 分**；同一对搭档仅计 1 次，换不同搭档可无限叠加 |

> **同分排序规则**：排行榜严格先按**是否点 Star**（已点 Star 在前）与**总分降序**排列；若多人积分相同，依次按**送出寄语数**（多者在前）、**收到寄语数**（多者在前）、**上墙时间**（早者在先）与 **GitHub 用户名**字典序决出先后。

## 二、纯排名百分位轨道分层与典藏名片效果

展示墙由两套联动机制组成：**典藏名片特效点亮 Star 即满配解锁**，而 **3D 太阳系中的行星体量与所在轨道则采用纯排名百分位动态分区**——不设固定分数线，排名越靠前，行星体积越庞大、轨道越靠近中央恒星。

### 1. 3D 太阳系轨道层级（Star 门禁 + 纯排名百分位）

- **Star 门禁（Star Gate）**：必须先给本仓库点亮 **Star** 才能入轨参与星系排名；未点 Star 的同学将作为小型岩质小行星在最外侧的 **外缘星带** 稳定运行。
- **TOP 1 & TOP 2–5 内环**：已点 Star 的同学按积分排名，**第 1 名**直接化身星系中心的巨型 **#1 恒星王座**，**第 2–5 名**入驻紧邻恒星的 **TOP 2–5 内环（恒星近卫）**。
- **TOP 5 之后的其余星标同学（池内纯排名百分位）**：按实时积分排序后，纯粹依据在 TOP 5 之后池内（共 `M = 已点 Star 人数 - 5` 人）的**排名百分位**划入三阶行星轨道：
  - **三阶 · 顶格传说**：TOP 5 之后**前 15%**（大型气态巨星）
  - **二阶 · 觉醒进化**：TOP 5 之后 **15%–50%**（中型冰巨星）
  - **一阶 · 初醒破框**：TOP 5 之后**后 50%**（小型类地行星）

| 轨道层级 | 判定规则 | 所在轨道 | 行星体量与外观 |
| --- | --- | --- | --- |
| 默认星体（门禁外） | 未点 Star | 外缘星带 | 小型灰色岩质小行星，混在小行星带中公转；完整展示你的名片与寄语，不影响任何培训任务 |
| **一阶 · 初醒破框** | 已点 Star，位于 **TOP 5 之后后 50%** | 一阶轨道 | 小型类地行星（含大陆、海洋、极地冰冠与云层地貌），按专属配方获得星环、卫星与公转尾迹 |
| **二阶 · 觉醒进化** | 已点 Star，位于 **TOP 5 之后 15%–50%** | 二阶轨道 | 中型冰巨星（青蓝与靛紫流云纹理、极地涡旋），体量显著大于一阶行星并向恒星靠拢 |
| **三阶 · 顶格传说** | 已点 Star，位于 **TOP 5 之后前 15%** | 三阶轨道 | 大型气态巨星（湍流云带与风暴斑），体量庞大，距离 TOP 5 内环仅一步之遥 |
| **TOP 2–5 恒星近卫** | 已点 Star，积分榜**第 2–5 名** | TOP 2–5 内环 | 超级气态巨星，拥有更宏大的体量与专属光环，名字常驻显示 |
| **#1 恒星王座** | 已点 Star，积分榜**第 1 名** | 星系中心 | 化身巨型中央恒星地标，头像映在日冕之中，并环绕金色王座星环 |

> **小班人数自适应兜底规则**：当已点 Star 且位于 TOP 5 之后的池内人数 `M` 较少时，系统会自动平滑兜底，避免小班初期出现反常识的阶位分配：
> - **`M = 1`**（TOP 5 之后仅 1 人）：归入 **一阶 · 初醒破框**（避免垫底却被标为「顶格传说」）。
> - **`M = 2`**（TOP 5 之后共 2 人）：第 6 名归入 **二阶 · 觉醒进化**，第 7 名归入 **一阶 · 初醒破框**（不跳阶）。
> - **`M >= 3`**：三阶截止名额取 `ceil(M × 15%)`（至少 1 席），二阶截止名额取 `max(三阶截止 + 1, ceil(M × 50%))`，其余归入一阶，确保**一阶、二阶、三阶全部都有分布**。

### 2. 典藏名片皮肤与 16 种顶格破框特效

点击任意星球或小行星即可打开个人典藏名片。名片皮肤与破框特效**只看是否点亮 Star**，而轨道阶位标签与晋级进度条则随你在 3D 星系中的实时排名百分位同步更新：

| 名片形态 | 解锁条件 | 名片角标 | 视觉与特效说明 |
| --- | --- | --- | --- |
| 默认卡片 | 未点 Star | `点star开放积分系统` | 标准简洁卡面，完整展示你的个人信息、头像与寄语，不影响任何培训任务 |
| **星标典藏卡（顶格破框）** | **已点 Star（直接解锁）** | `X分 · 一阶 / 二阶 / 三阶`（前五名为 `TOP N X分 · 近卫 / 王座`） | **点亮 Star 即直接解锁**专属七维卡面皮肤（配色、底纹、星标徽章）与 **16 种顶格破框血脉特效之一**（包含血脉主题角色/粒子动画与邻卡联动），并在卡片下方实时展示当前排名百分位与冲榜进度 |

## 三、怎么拿高分？结对编程（`Co-authored-by`）

Git 原生支持把同一份提交归功于多位合作者。只要你和另一位**已上墙同学**一起修改文件，并在 `commit message` 末尾空一行加上标准的 `Co-authored-by` trailer，待 PR 合入主仓库 `main` 后，**提交者与搭档双方各自获得 +2 分**：

```bash
git commit -m "feat: pair programming on profile update

Co-authored-by: 同学用户名 <同学用户名@users.noreply.github.com>"
```

> **如何避免踩坑（防作弊校验规则）**：
> - `Co-authored-by:` 之前必须保留**至少一个空行**，尖括号内推荐填写对方的 GitHub noreply 邮箱（`<用户名>@users.noreply.github.com` 或 `<ID>+<用户名>@users.noreply.github.com`），系统也可通过已上墙的 GitHub 用户名匹配。
> - 双方都必须是已合入 `data/profiles/` 的真实上墙同学（幽灵账号、自己写自己均无效）。
> - 该 commit 必须包含至少 **1 个实质文件改动**（`git commit --allow-empty` 空提交不计分），且**必须通过 PR 真正合入 `main`**。
> - 单个 commit 最多支持标注 **2 位**真实搭档（超过 2 位视为批量挂名刷分，整条提交不计结对分），且仅计提交者本人与各搭档之间的配对。
> - 同一对搭档（不论谁提交、谁做 Co-author，`A+B` 与 `B+A` 视为同一对）只计 1 次 `+2 分`；但你可以和 **2 位、3 位甚至更多不同同学**结对协作，每多一位新搭档就再 `+2 分`！
> - 实用场景：例如帮尚未熟悉流程的同学一起完善他的卡片 / 寄语 PR，或者结对给别的同学写寄语时在 commit 里加上对方的 `Co-authored-by`。

## 四、专属皮肤与进阶冲榜路线

- **点 Star 即刻解锁顶格卡面与 16 种血脉特效**：点亮 Star 后，系统会根据你的 GitHub 用户名自动匹配一套碰撞最少的七维配方（包含卡面主题、星环、卫星、徽章与 **16 种顶格破框血脉特效**之一），**无需攒分门槛即可在名片中直接释放满配破框动画**；而 3D 太阳系中的行星大小与轨道层级则由全班实时排名百分位决定。
- **进阶冲榜路线（提升排名百分位 → 进军前 15% / TOP 5 / 恒星王座）**：
  1. **点 Star 入轨（`+1 分`）**：立刻告别外缘岩质小行星带，入轨成为参与星系排行的彩色行星，并解锁满配典藏名片。
  2. **写满 3 份不同同学的寄语（最高 `+3 分`，累计 `4 分`）**：寄语上限为 `3 分`，先给 3 位不同同学合入走心寄语，就能迅速与只点 Star 的同学拉开差距，稳步向 **二阶（前 15%–50%）** 跃迁。
  3. **多搭档结对冲刺（`Co-authored-by` 每位新搭档 `+2 分`，不封顶）**：因为纯排名百分位没有固定天花板，每多与一位**不同同学**完成一次有效结对提交，就能稳定 `+2 分`——完成 2–3 组不同搭档结对通常即可冲进 **TOP 5 之后前 15%（三阶大型气态巨星）**，继续积累更多搭档就能进一步冲击 **TOP 2–5 恒星近卫内环** 甚至夺下 **#1 恒星王座**！
  4. **随时查看名片进度条**：点开自己的星球名片，即可看到当前在全班星标池中的精确排名与百分位，以及距离下一阶守门人还差几名、还差几分反超。

## 五、展示墙浏览与交互说明

- **3D 星系**：拖拽旋转、滚轮缩放、右键平移；每条轨道都有独立倾角，换个角度就能看清立体结构。按 `V` 可在仰望、俯瞰、掠过星带、神明一瞥四种机位间切换，按空格暂停 / 继续公转。
- **点击星球**：打开同学的典藏名片，并点亮 TA 的寄语与结对连线（蓝色为送出、粉色为收到、金色为结对）；再次点击或双击可让镜头跟随这颗星球。名片右上角的星标徽章可以随时再次释放破框特效。
- **群星榜**：页面左侧列出全班所有同学的排名（包括尚未点 Star 的同学），列表会缓慢无缝滚动，鼠标移入即暂停；点击任意一行即可飞向该同学。
- **实时变化**：新同学上墙会化作流星坠入星系，新寄语会以彗星飞向收件人，排名升阶时行星会沿弧线跃迁到更内侧的轨道。
- **搜索**：左下角输入名字、GitHub、城市或寄语，回车即可飞向对应星球；按 `/` 快速聚焦搜索框。
